Шаг 1.1 Найди все ссылки t.me/ в тексте поста. Определи идентификатор канала из ссылки - все, что после t.me/ИМЯКАНАЛА

## РЕКЛАМА
Шаг 3. Дополнительные сигналы (повышают ad_rate):
- Приватная invite-ссылка t.me/+HASH вне белого списка — ad_rate >= 0.9
- Продажа товаров, услуг, ставки, казино, курсы, прогнозы — ad_rate = 1.0
- Кликбейт: "шокировало", "секрет", "заработай", "проверено", "успей" — ad_rate >= 0.8
- ссылка на продолжение истории или полное видео — ad_rate >= 0.8
- открытки, оригинальные поздравления, уникальный контент
- приглашения и предложения ограниченные по времени
- ссылка на оригинальные поздравления

## НЕ РЕКЛАМА (белый список продолжение)
- Мемы, шутки, смешные видео с короткой подписью или эмодзи — без ссылок на чужие каналы.
- Бытовые наблюдения, реакции на происходящее.
- Канал упоминает СЕБЯ по имени — это своя плашка, не реклама.
- призывы подписаться на свой канал или канал из белого списка - не реклама, игнорировать!
